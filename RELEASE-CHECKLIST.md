# Release Checklist

- [ ] README accurately describes the book
- [ ] CONTENTS links work
- [ ] START-HERE links work
- [ ] Every chapter has navigation
- [ ] Every Part has a landing page
- [ ] Mermaid diagrams render
- [ ] Customer relationships are sourced
- [ ] Partner relationships are sourced
- [ ] Contemporary metrics are dated
- [ ] Bibliography is current
- [ ] Evidence gaps are documented
- [ ] No unsupported claims are presented as fact
- [ ] No placeholder text remains
- [ ] No TODO markers remain unless intentionally documented
- [ ] No generated junk files are tracked
- [ ] Repository status is clean before release

This checklist is intentionally manual. It keeps the publication format simple while making the final evidentiary and reader-journey review explicit.
